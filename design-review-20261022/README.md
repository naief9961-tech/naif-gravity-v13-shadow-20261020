# NAIF GRAVITY — safe visual design preview (2026-10-22)

This folder is an intentionally independent **public, design-only** preview. It is not the NAIF Gravity production storefront and does not include private product code, live agents, paid paths, credentials, webhook endpoints, account logic or checkout.

- `index.html` + `review.css` + `review.js`: simplified static design and three synthetic glass visual stages. Only the cosmetic glass illustration responds to clicks.
- `assets/`: four screenshots taken from a separately held V14 Shadow build by Mac Chromium/WebKit QA. They are not physical iPhone screenshots, nor proof of product functionality.
- Mission Arena and Future Shield are **coming soon**, with illustrative planned prices; neither product is available for purchase or certified as a real-world security guard.
- Original Crystal Whisper is now delivered through three self-hosted 48 kHz PCM WAV files (1680/2510/3560 Hz, original envelopes and relative phases), normalized by a single common gain factor to make the same timbre audible on smaller iPhone speakers. Native HTMLMediaElement playback avoids known iOS WebAudio silent-switch problems.
- Audio is OFF by default on each visit; enabling immediately plays the selected chime. A native audio-controls fallback remains available for iPhone diagnostics. No preference storage, telemetry, trackers, analytics, external scripts, APIs, or payment gateways.
- Reproducing this visual preview is free of new ongoing service fees; it is hosted under a previously established public GitHub Pages design-shadow repository.
- The original V13 preview remains in the repository root and is unchanged by this subdirectory.
- No production deployment or commercial release authorization is inferred from publishing this public-facing visual sample.

A successful browser test here proves only that this independent visual sample renders and responds; the owner must separately check the full private V14 build on a real iPhone Safari/VoiceOver through an authorized secure path.
